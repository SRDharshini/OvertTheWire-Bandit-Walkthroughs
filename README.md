# OverTheWire — Bandit Walkthrough

A personal documentation of my hands-on progress through the 
OverTheWire Bandit wargame. Each level includes my approach, 
the commands I used, and key takeaways — written to reflect 
genuine problem-solving, not just final answers.

## About This Repository
OverTheWire Bandit is a beginner-friendly wargame designed to 
teach Linux fundamentals and core cybersecurity concepts through 
practical challenges. This repository serves as both a learning 
journal and a technical reference.
